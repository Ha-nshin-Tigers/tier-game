# みんなのあそびば(みんなでティア表 / かくれナンバー / ウソつき酒場 / ミニゲーム集)

ログインなしで遊べるオンラインパーティーゲーム集。`/` のホーム画面でゲームを選ぶ。

## みんなでティア表(`/tier`)

親が5つのワードを 1位〜5位 に並べ、ほかのプレイヤーが制限時間内にその並びを予想して得点を競うオンラインパーティーゲーム。
ログイン不要。ニックネームと部屋コードを入れるだけで遊べる。

## 構成

| ファイル | 役割 |
|---|---|
| `server.js` | ゲームサーバ(HTTP + WebSocket)。部屋・タイマー・得点計算・お題の保存。WebSocket の振り分け |
| `public/index.html` | ゲームを選ぶホーム画面。URL は `/` |
| `public/tier.html` | ティア表の画面(入室・ゲーム・お題コレクション)。URL は `/tier`(以前の `/?room=` 形式の招待リンクは `/tier?room=` へ転送) |
| `games/number.js` | かくれナンバーのゲームサーバ(WebSocket は `/number/ws`) |
| `public/number.html` | かくれナンバーの画面。URL は `/number` |
| `games/liar.js` | ウソつき酒場のゲームサーバ(WebSocket は `/liar/ws`) |
| `public/liar.html` | ウソつき酒場の画面(3D/2D)。URL は `/liar` |
| `games/party.js` | ミニゲーム集のゲームサーバ(WebSocket は `/party/ws`。単独ゲームも大会も共通) |
| `public/party.html` | ミニゲーム集の画面。URL で遊び方が変わる: `/bridge` `/bomb` `/memory`(単独)、`/party`(ドタバタ大会) |
| `public/models/` | 3Dモデル(ライセンスは同じフォルダの README.md) |
| `render.yaml` | Render にデプロイするための設定 |

- 親の答えはサーバだけが持ち、答え合わせまでほかのプレイヤーには送らない
- 部屋のデータはサーバのメモリ上にある(サーバが再起動すると進行中のゲームと得点は消える)
- 「みんなのお題」は Upstash Redis に保存(未設定ならローカルの `data/topics.json`)

## 得点

- 順位がぴったり: 3点
- 1つずれ: 1点
- 5つ全部ぴったり: ボーナス5点

## かくれナンバー(`/number`)

数字をことばで伝えて、みんなで小さい順に並べる協力ゲーム(2〜12人)。

1. 全員に 1〜100 の数字が1つずつこっそり配られる(重複なし)
2. お題(例: 怖いもの。1=平気 / 100=震えるほど怖い)に沿って、自分の数字の大きさを「ことば」で表す
3. 全員のヒントがそろったら、話し合って小さい順に並べる(誰が動かしても全員に反映。動くと全員のOKは取り消し)
4. 全員が「この並びでOK」で公開。全部正しい順番なら成功、違えばライフ -1(ライフ 1/3/5/なし をホストが選ぶ)

- 各自の数字はサーバだけが持ち、公開まで本人以外には送らない
- 部屋はティア表とは別管理(同じ部屋コードでも別の部屋)。お題は `games/number.js` の `TOPICS`。保存はしない
- ホストはお題の引き直し・自由入力・ヒント待ちの打ち切り・今すぐ公開ができる

## ウソつき酒場(`/liar`)

カードのブラフ+ロシアンルーレット(2〜6人、通話しながら遊ぶ想定)。

1. ラウンドごとに「テーブルカード」(キング・クイーン・エース)が決まり、5枚ずつ配る。ジョーカーは何にでもなる
2. 手番の人は 1〜3枚 を伏せて出し「全部テーブルカード」と言い張る(ウソでもよい)
3. 次の人は自分も出すか「ウソつき！」と指摘する。手札がない人は指摘するしかない
4. 指摘したら公開。ウソなら出した人、本当なら指摘した人が自分のリボルバーの引き金を引く(6発中1発が実弾。引くたびに当たりやすくなる)
5. 撃たれたら脱落。最後の1人が勝ち

- 山札は4人までは20枚(K・Q・A 各6 + ジョーカー2)、5人以上は30枚(各9 + ジョーカー3)
- 手札・弾の位置はサーバだけが持つ。手札は本人にだけ送り、出したカードは指摘されたときだけ公開
- 1手の制限時間(30秒/60秒/なし)を過ぎると自動で1枚出すか指摘する。引き金は20秒で自動
- 一言スタンプ(10種類)。3D表示では頭の上に吹き出しで出る
- 3D表示は three.js(`package.json` の依存。`/vendor/three/...` として配信)。使えない端末では自動で2D表示

## ミニゲーム集(単独: `/bridge` `/bomb` `/memory`、大会: `/party`)

3種のミニゲーム(2〜8人)。試合ごとの順位点(1位10・2位7・3位5・4位3・5位2・6位以下1)で競う。

- **単独**: そのゲームだけを遊ぶ。結果のあと「もう一度遊ぶ」で同じメンバーのまま次の試合へ(順位点は通算)
- **ドタバタ大会**: ホストが試合を好きな順番・好きな数で並べる(同じゲームを何回でも、最大9試合)。続けて遊び、合計で総合優勝
- 部屋は遊び方ごとに別(同じ部屋コードでも `/bridge` と `/bomb` は別の部屋)

- **ひとりじめ橋**: 点数付きの橋(人数分、最低3本)から全員がこっそり1本選ぶ(15秒)。自分だけが選んだ橋ならその点、かぶった橋は崩れて0点。3ラウンド
- **爆弾回し**: 爆弾を持っている人が相手を選んで渡す。爆発時刻(9〜22秒のランダム)はサーバだけが知る。爆発時に持っていた人が脱落、最後の1人が1位。受け取ってから0.7秒は渡せない
- **おぼえて料理**: 材料を4秒見せたあと、12個の食材から選んで提出。正解+2・まちがい−1・全問正解+2、全問正解の早い順に+3/+2/+1。材料は3→4→5個

秘密の情報(ほかの人の選択・爆発時刻・入力中のレシピ)は公開の段階まで送らない。

## 手元で動かす

Node.js 18 以上が必要。

```bash
npm install
npm start
```

http://localhost:3000 を開く(ホーム画面。ティア表は `/tier`、かくれナンバーは `/number`、ウソつき酒場は `/liar`、ミニゲームは `/bridge` `/bomb` `/memory`、ドタバタ大会は `/party`)。

## Render に公開する

1. このフォルダを GitHub のリポジトリに push する
2. https://render.com に GitHub アカウントでログイン
3. 「New +」→「Blueprint」→ リポジトリを選ぶ(`render.yaml` が読み込まれる)
4. 「Apply」でデプロイ。数分で `https://tier-game-xxxx.onrender.com` のような URL ができる

無料プランは15分ほど誰も使わないと休止し、次の接続で起動するまで30秒〜1分かかる。

## お題をずっと残す(Upstash Redis)

Render 無料プランではサーバのファイルが再起動で消えるため、お題は外部に保存する。

1. https://upstash.com に登録(無料)し、Redis データベースを作る
2. データベース画面の「REST API」にある `UPSTASH_REDIS_REST_URL` と `UPSTASH_REDIS_REST_TOKEN` をコピー
3. Render のサービス画面 →「Environment」に2つを設定して保存(自動で再デプロイされる)

設定しなくてもゲームは遊べるが、お題はサーバの再起動のたびに消える。
