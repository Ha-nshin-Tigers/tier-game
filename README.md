# みんなのあそびば(みんなでティア表 / かくれナンバー / ウソつき酒場 / 散弾ルーレット / ミニゲーム集)

ログインなしで遊べるオンラインパーティーゲーム集。`/` のホーム画面でゲームを選ぶ。

## みんなでティア表(`/tier`)

親が5つのワードを 1位〜5位 に並べ、ほかのプレイヤーが制限時間内にその並びを予想して得点を競うオンラインパーティーゲーム。
ログイン不要。ニックネームと部屋コードを入れるだけで遊べる。

## 得点

- 順位がぴったり: 3点
- 1つずれ: 1点
- 5つ全部ぴったり: ボーナス5点

## かくれナンバー(`/number`)

数字をことばで伝えて、みんなで小さい順に並べる協力ゲーム(2〜12人)。

1. 全員に 1〜100 の数字が1つずつこっそり配られる(重複なし)
2. お題(例: 怖いもの。1=平気 / 100=震えるほど怖い)に沿って、自分の数字の大きさを「ことば」で表す
3. 全員のヒントがそろったら、話し合って小さい順に並べる(誰が動かしても全員に反映。動くと全員のOKは取り消し)
4. 全員が「この並びでOK」で公開。全部正しい順番なら成功、違えばライフ -1(ライフ 1/3/5/なし をホストが選ぶ)

- 各自の数字はサーバだけが持ち、公開まで本人以外には送らない
- 部屋はティア表とは別管理(同じ部屋コードでも別の部屋)。お題は `games/number.js` の `TOPICS`。保存はしない
- ホストはお題の引き直し・自由入力・ヒント待ちの打ち切り・今すぐ公開ができる

## ウソつき酒場(`/liar`)

カードのブラフ+ロシアンルーレット(2〜6人、通話しながら遊ぶ想定)。

1. ラウンドごとに「テーブルカード」(キング・クイーン・エース)が決まり、5枚ずつ配る。ジョーカーは何にでもなる
2. 手番の人は 1〜3枚 を伏せて出し「全部テーブルカード」と言い張る(ウソでもよい)
3. 次の人は自分も出すか「ウソつき！」と指摘する。手札がない人は指摘するしかない
4. 指摘したら公開。ウソなら出した人、本当なら指摘した人が自分のリボルバーの引き金を引く(6発中1発が実弾。引くたびに当たりやすくなる)
5. 撃たれたら脱落。最後の1人が勝ち

- 山札は4人までは20枚(K・Q・A 各6 + ジョーカー2)、5人以上は30枚(各9 + ジョーカー3)
- 手札・弾の位置はサーバだけが持つ。手札は本人にだけ送り、出したカードは指摘されたときだけ公開
- 1手の制限時間(30秒/60秒/なし)を過ぎると自動で1枚出すか指摘する。引き金は20秒で自動
- 一言スタンプ(10種類)。3D表示では頭の上に吹き出しで出る
- 3D表示は three.js(`package.json` の依存。`/vendor/three/...` として配信)。使えない端末では自動で2D表示

## ミニゲーム集(単独: `/bridge` `/bomb` `/memory`、大会: `/party`)

3種のミニゲーム(2〜8人)。試合ごとの順位点(1位10・2位7・3位5・4位3・5位2・6位以下1)で競う。

- **単独**: そのゲームだけを遊ぶ。結果のあと「もう一度遊ぶ」で同じメンバーのまま次の試合へ(順位点は通算)
- **ドタバタ大会**: ホストが試合を好きな順番・好きな数で並べる(同じゲームを何回でも、最大9試合)。続けて遊び、合計で総合優勝
- 部屋は遊び方ごとに別(同じ部屋コードでも `/bridge` と `/bomb` は別の部屋)
- 大会にはティア表・かくれナンバー・ウソつき酒場・散弾ルーレット・絵しりとりの「大会版」(`games/mini/`)も並べられる
  - ティア表: 全員が1回ずつ親。得点は元と同じ。親が60秒で並べなければランダムに並べて進める
  - かくれナンバー: 3ラウンド。自分のカードが正しい位置なら+2、全員そろったら全員+1
  - ウソつき酒場: ルールは同じ(2D表示)。7〜8人は山札40枚。脱落が遅いほど上位
  - ゲームを足すときは `games/mini/` に start / handle / view / onLeave を持つファイルを置き、`games/party.js` の `MINI` と `public/party.html` の `GAME_INFO` に登録する

- **ひとりじめ橋**: 点数付きの橋(人数分、最低3本)から全員がこっそり1本選ぶ(15秒)。自分だけが選んだ橋ならその点、かぶった橋は崩れて0点。3ラウンド
- **爆弾回し**: 爆弾を持っている人が相手を選んで渡す。爆発時刻(9〜22秒のランダム)はサーバだけが知る。爆発時に持っていた人が脱落、最後の1人が1位。受け取ってから0.7秒は渡せない
- **おぼえて料理**: 材料を4秒見せたあと、12個の食材から選んで提出。正解+2・まちがい−1・全問正解+2、全問正解の早い順に+3/+2/+1。材料は3→4→5個

秘密の情報(ほかの人の選択・爆発時刻・入力中のレシピ)は公開の段階まで送らない。

## 散弾ルーレット(`/shotgun`)

実弾と空砲のショットガン(2〜6人)。ルール本体は `games/mini/shotgun.js` で、単独ゲームとドタバタ大会で共通。

1. 2〜8発(実弾・空砲を最低1発ずつ)を込める。発数は公開、順番は秘密
2. 自分の番に、ほかの人か自分を撃つ。自分を撃って空砲なら、もう一度自分の番
3. 実弾でライフ−1(ノコギリ使用時は−2)。0で脱落。弾がなくなると込め直し、アイテムを2つずつ配る(最大8個)
4. 最後の1人が勝ち

アイテム(ホストが使う種類を選べる): 虫メガネ(今の弾を見る・本人だけ)/タバコ(ライフ+1)/ビール(今の弾を抜く・全員に公開)/手錠(番の順で次の人を1回休み)/ノコギリ(次の1発ダメージ2)/期限切れ薬(50%で+2、50%で−1)/使い捨て携帯(先の1発の種類が分かる・本人だけ)/インバータ(今の弾の実弾と空砲を入れ替え)/アドレナリン(相手のアイテムを奪ってすぐ使う)/ジャマー(選んだ相手を1回休み)/リモコン(番の向きを逆に)

- 弾の並びはサーバだけが持つ。虫メガネ・携帯の結果は使った本人にだけ送る
- ホストが変えられる細かいルール: ライフ2〜6、1手の制限時間30秒/60秒/なし(時間切れはほかの人をランダムに撃つ)、
  込める弾の数(2〜4/2〜8/5〜8発)、実弾の割合(少なめ/ふつう/多め)、1回に配るアイテム(0〜4個・1〜4個ランダム)、
  アイテムの上限(4/6/8個)、アイテムごとの出やすさ(出ない/少ない/ふつう/多い)、1回の配布で同じアイテムを重ねない、
  自分を撃って空砲ならもう一度自分の番(する/しない)。「おすすめ設定に戻す」あり
- 大会版は2D表示・ライフ4・制限時間40秒

## 絵しりとり(`/eshiri`)

絵だけでしりとりをつなぐ(2〜8人)。ルール本体は `games/mini/eshiri.js` で、単独ゲームとドタバタ大会で共通。

1. 自分の番になったら、前の人の絵を見て「何の絵か」を推理して入れる(最初の人はお題の言葉から)
2. その最後の文字から始まる言葉を考えて、絵だけで描く(文字は描かない)。描いた言葉は答え合わせまで秘密
3. 「ん」で終わる言葉はだめ。前の絵を「ん」で終わる言葉だと読んだら、好きな文字から始めてよい
4. 最後に答え合わせ。読み取り(①)が前の人の描いた言葉と一致すれば「つながった」

ホストが選べる設定:
- 進め方: 1本のしりとりを順番に(周回1〜3周、見え方「前の絵だけ」/「みんなに見える(実況)」)、
  または全員同時に人数分のしりとりを回す(お絵かき伝言ゲーム風・待ち時間なし)
- 点数: 協力のみ(初期設定。何か所つながったかだけ)/個人戦+協力(読み取れたら+2点、自分の絵を読み取ってもらえたら+1点)
- 描く時間: 45秒/60秒/90秒/なし(時間切れはその時点の絵と言葉で提出。ホストは「締め切る」で止まった番を進められる)

- 描いた言葉と、まだ見てはいけない絵はサーバが送らない(前の絵は次の人の番になってから届く)
- 大会版は「1本のしりとり・1周・前の絵だけ・60秒」。答え合わせは90秒(ホストは「結果へ」で先に進める)。順位は個人戦の点数

## 不動産王(`/monopoly`)

モノポリー風のボードゲーム(2〜8人)。ルール本体は `games/mini/monopoly.js`。マスの並び・値段・使用料・カードは本家と同じで、名前だけ差し替えている(地図: 日本/世界)。

- サイコロ2つで進む。スタートを通ると200万。ゾロ目はもう一回、3回続くと刑務所
- 持ち主のいない土地は買える。買わなければ全員で競売(最後の入札から12秒で締め切り)
- 人の土地に止まったら使用料。同じ色を全部持つと2倍、家1〜4軒→ホテルで上がる。駅は持っている数、公共会社はサイコロの目で決まる
- 建物は同じ色に均等に建てる・売る(半額)。銀行の家32軒・ホテル12軒が在庫
- 抵当で半額を借りられる(外すときは1割増し)。抵当中は使用料なし、建物のある色は抵当に入れられない
- プレイヤー同士の取引(土地・お金・刑務所カード)。抵当中の土地を受け取ったら利子1割
- 刑務所: ゾロ目・保釈金50万・出られるカードで出所。3回目も失敗なら50万払って出る
- チャンス・共同基金カード16枚ずつ
- 払えないときは、家を売る・抵当・取引でお金を作る。払えなければ破産(財産は相手へ。銀行への破産は銀行へ戻る)。最後の1人が勝ち
- ホストが選べる設定: 地図(日本/世界)、最初のお金(1000/1500/2000万)、1手の持ち時間(60/90/120秒/なし)
- 細かいルール(ホストが1つずつ切り替え。「本家どおり」「オリジナル」ボタンで一括。初期は本家どおり):
  - 銀行への破産で戻った土地を競売にする(オリジナル: 銀行のものに戻すだけ)
  - 破産で抵当中の土地を受け取ったら、すぐ利子1割を払う(オリジナル: 利子なし)
  - 抵当中の土地を受け取ったその番のうちは、元金だけで抵当を外せる(オリジナル: いつでも1割増し)
  - 競売で、売却・抵当で作れるお金まで入札できる。足りない分は落札後に払う(オリジナル: 現金まで)
  - 銀行の家が残り4軒以下で、ほかにも建てたい人がいれば家を1軒ずつ競売(家の値段以上。オリジナル: 早い者勝ち)
  - 何人かに払えずに破産したら、現金は払う額に応じて分け、土地は銀行へ(本家に決まりはない。オリジナル: 最初の相手に全部)
  - 無料駐車場に税金・罰金を貯めて、止まった人がもらう(ハウスルール。どちらのボタンでも「なし」)
- 時間切れ(切断中の人は30秒)は自動で進める: サイコロを振る・土地は競売へ・支払いは自動で売却と抵当
- このサイト独自: 持ち時間と自動進行、抜けた人は破産扱い(財産は銀行へ)、取引の提案は1人3件まで・競売中は取引できない

## インサイダー(`/insider`、インサイダーゲーム風)

4〜8人。役職はマスター(公開・お題を知る)、インサイダー(秘密・お題を知る)、庶民(お題を知らない)。

1. マスターはお題を確認(3回まで変えられる)して質問タイム開始(5分。3分/7分にも変えられる)
2. みんなでマスターに「はい/いいえ」で答えられる質問をする。通話で話しても、画面に書いてもよい(マスターは はい/いいえ/わからない/正解！ を押す)
3. だれかがお題を言い当てたら、マスターがその人を選んで「正解！」。お題は全員に公開され、かかった時間と同じだけ話し合い
4. 投票1「答えた人はインサイダー？」(答えた人以外)。過半数なら答え合わせ: その人がインサイダーなら庶民側の勝ち、違えばインサイダーの勝ち
5. 過半数でなければ投票2「インサイダーはだれ？」(全員)。最多の1人がインサイダーなら庶民側の勝ち。違う人・同票ならインサイダーの勝ち
6. 時間内にお題を当てられなければ全員の負け。ラウンドごとの勝ち数を表示。マスターは順番に交代(毎回ランダムにもできる)

- お題(200語)はサーバだけが持ち、マスターとインサイダーにだけ送る。インサイダーがだれかは結果まで送らない
- マスターかインサイダーが抜けたら、そのラウンドは流れる

## コヨーテ(`/coyote`、Coyote 風)

2〜10人。山札は本家と同じ36枚: 20×1・15×2・10×3・5〜1×各4・0×3・−5×2・−10×1 と、特殊カード ×2・MAX→0・？・夜(0)。

1. 全員に1枚ずつ配る。ほかの人のカードは見えるが、自分のカードだけ見えない(サーバは本人にだけ伏せて送る)
2. 順番に「全員の合計は○○以上」と前より大きい数を言う。言いすぎだと思ったら「コヨーテ！」(最初の人はできない)
3. 公開して合計を計算: ？(山札の上をめくって足す)→ MAX→0(いちばん大きい数字1枚を0に)→ ×2(合計を2倍)の順
4. 言った数が合計より大きければ言った人、合計以下ならコヨーテした人のライフ−1(本家どおり3。1〜5に変更可)。ライフ0で脱落、最後の1人が勝ち
5. 次の回は負けた人から(脱落したらその次の人から)。夜が出た回のあとは山札を全部まぜ直す
- 設定: ライフ、1手の持ち時間(30/60/90秒/なし。時間切れは最初の人は1を言い、2人目からはコヨーテ)、特殊カードあり/なし
- 本家で決まりがはっきりしない所の決め方: ？で特殊カード(×2・MAX→0・？)が出たら捨てて引き直す(夜なら0)。MAX→0 で同じ数字が並んだら1枚だけ0にする

## チャレンジャーズ(`/challengers`、Challengers! 風)

2〜8人(奇数のときはロボットが入る)。カード(スターター4種・レベルA/B/C、各セット40枚+都市20枚)の名前・パワー・枚数・効果は
[くり坊さんの早見表](https://kuribodo.com/bga_challengers/)、ルールは公式ルールブックと Board Game Arena の説明に合わせた。

1. 全7ラウンド。デッキフェイズ: 選べる山から5枚見て1〜2枚をデッキへ(1回だけ引き直し可)。そのあとデッキから好きなだけ外せる(スターターは箱へ、ほかは捨て札へ)
   - 選べる山: R1・R2 Aから2枚 / R3 Aから2枚かBから1枚 / R4 Aから2枚かBから2枚 / R5 Bから2枚 / R6 Bから2枚かCから1枚 / R7 Cから2枚(R2 は資料が見つからず R1 と同じとした)
2. マッチフェイズ: 対戦表(総当たり)で1対1。サーバが自動で進める。旗を持つ側のカード1枚に、攻撃側がデッキの上から1枚ずつ出して合計が同じか上回れば旗を奪う
   - 奪われたカード(とその下のカード)はベンチへ。ベンチは6席(同じ名前は同じ席)。席が足りない、または攻撃でデッキが尽きたら負け
   - 効果のタイミング(公開時・攻撃中・ベンチ時・旗の所持中・旗を失った時・選んだ時)と、すべてのカードの効果を実装。選ぶ必要がある効果は本人に聞く(20秒で「おまかせ」)
3. 勝つとそのラウンドのトロフィー(裏のファン数は本人だけ見える)。7ラウンド後、ファンの多い2人で決勝(同点はトロフィー数→いちばん新しいラウンドのトロフィー)。決勝の前にデッキを削れる
4. 2人のときは決勝なし。ファンが多い方の勝ち、11人差がついたらその場で勝ち

- 設定: 使わないセット(ランダム/指定)、デッキフェイズの時間、マッチの速さ
- 本家と違うところ: ロボットの専用デッキは公開されていないため、ロボットは毎ラウンド自分でカードを選ぶ(パワーの高い順)。UFO の「デッキの上/下」は資料で食い違いがあり、「下」とした

## エルドラドを目指して(`/eldorado`、The Quest for El Dorado 風)

2〜4人(2人のときは1人2コマ。スタート1・3番と2・4番)。ルールは公式ルールブックに合わせた。

1. 初期デッキは探検家3・旅行者4・水夫1。手札4枚。カード1枚のパワーで、同じ種類のとなりのマスへ進む(マスの記号の数=必要なパワー)。残ったパワーで続けて進める。カードは合算できない
2. 荒地は手札を指定枚数捨て、ベースキャンプは指定枚数をゲームから除外して入る。山・ほかのコマのいるマスには入れない
3. 1ターンに1枚まで購入(進み終わってから)。コインのカードはパワー分、ほかは0.5コイン。市場6種(各3枚)。市場に空きがあれば市場の外のカードも買え、その山を空きに置く
4. アクションカードと1回限りのカードを実装。使わなかった手札は残してよい
5. ボードの境目のバリケードは最初に通る人が取り除いて得る。だれかがエルドラドに着いたら、そのラウンドの最後の人まで遊んで終了。着いた人の中でバリケードの数→最大番号で勝ち

- コース: 基本ルールブックの7コース(はじめての探検・最後の直線・黄金の丘・曲がりくねった道・うねる道・魔女の大釜・湿地帯)と、英雄と呪いの6コース
- 設定「洞窟ルール」: 洞窟のある山のとなりに止まると洞窟トークン(36個。種類ごとの数は公式ルールブック独語版の表記どおり)
- 設定「拡張 英雄と呪い」: 魔物マス・トンネル・呪い20枚・魔物カード15枚・酒場の英雄10人・動物カード4枚・新しい市場カード4種・魔物バリケード2つ・洞窟トークン18個。洞窟ルールも必ず入る(公式どおり)

### データの出典と推定
- 地形タイルのマス: A〜N は [ShlomoAlon/el-dorado](https://github.com/ShlomoAlon/el-dorado) の `engine_data.js` を、[BoardGameHelpers の地形タイル一覧](https://www.boardgamehelpers.com/QuestforElDorado/TileCatalogue.aspx)の画像と照合。E・H・帯タイル O〜R・拡張タイル S〜X と洞窟の位置は同一覧の画像から写した。全タイルで地形ごとのマス数が同一覧と一致
- コースの配置: BoardGameHelpers の公式コース表示から換算(「はじめての探検」のみ ShlomoAlon/el-dorado の配置)
- カード: [エルドラド攻略サイト](https://sites.google.com/view/eldorado17/)。拡張の英雄・呪いの内訳・動物カード・新カードは公式ルールブック(英・独)と国内レビュー記事
- **推定**: 拡張の洞窟トークン18個の種類ごとの内訳(公表資料が見つからない。魔物払い5・呪いよけ5・地質学者の一歩4・市場への道4とした)
- 入れていないもの: 拡張「黄金の神殿」(ルールブックとタイルの資料が手に入らないため)、プロモカード

## 手元で動かす

Node.js 18 以上が必要。

```bash
npm install
npm start
```

http://localhost:3000 を開く(ホーム画面。ティア表は `/tier`、かくれナンバーは `/number`、ウソつき酒場は `/liar`、ミニゲームは `/bridge` `/bomb` `/memory`、散弾ルーレットは `/shotgun`、絵しりとりは `/eshiri`、不動産王は `/monopoly`、ドタバタ大会は `/party`)。

## Render に公開する

1. このフォルダを GitHub のリポジトリに push する
2. https://render.com に GitHub アカウントでログイン
3. 「New +」→「Blueprint」→ リポジトリを選ぶ(`render.yaml` が読み込まれる)
4. 「Apply」でデプロイ。数分で `https://tier-game-xxxx.onrender.com` のような URL ができる

無料プランは15分ほど誰も使わないと休止し、次の接続で起動するまで30秒〜1分かかる。

## お題をずっと残す(Upstash Redis)

Render 無料プランではサーバのファイルが再起動で消えるため、お題は外部に保存する。

1. https://upstash.com に登録(無料)し、Redis データベースを作る
2. データベース画面の「REST API」にある `UPSTASH_REDIS_REST_URL` と `UPSTASH_REDIS_REST_TOKEN` をコピー
3. Render のサービス画面 →「Environment」に2つを設定して保存(自動で再デプロイされる)

設定しなくてもゲームは遊べるが、お題はサーバの再起動のたびに消える。
